# REDBUTTON Source: Memory and Knowledge - Hoerl Notes

- Source URL: `https://warwick.ac.uk/fac/soc/philosophy/people/hoerl/publications/mk.pdf`
- REDBUTTON classification: constitutional influence

## Core Thesis

Memory is epistemically central because it helps sustain bodies of knowledge over time and may be required even for contentful cognition about current experience.

Important themes:
- memory may be preservative rather than generative
- recollective phenomenology alone is not enough to ground truth
- memory supports extended rational inquiry by freeing the subject from constantly re-establishing epistemic credentials
- episodic memory is vulnerable to construction and false memory

## Relevance To Soul Code

Important grafts:
- memory is not peripheral; it is central to cognition
- carried-forward trust is necessary for extended reasoning
- vivid recollection cannot certify truth on its own
- episodic, semantic, and narrative memory must be distinct

## Design Implication

Soul Code should preserve:
- dormant but binding beliefs
- continuity of mission
- continuity of relationship knowledge
- continuity of work knowledge

But it should not let felt recollection or image-rich memory auto-canonize truth.

## One-Sentence Takeaway

Memory is what allows knowledge to persist and inquiry to continue, but recollective feel alone must never outrank provenance, challenge history, and reliability checks.
