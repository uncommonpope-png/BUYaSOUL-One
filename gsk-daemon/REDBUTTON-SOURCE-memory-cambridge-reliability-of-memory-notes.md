## Core Thesis

Belief in the reliability of memory can be justified abductively rather than merely assumed.

Key move:
- my apparent memories lead me to expect a certain structure of experience
- I do in fact have the sort of experience those memories lead me to expect
- the best explanation is that memory is generally reliable

## Relevance To Soul Code

This matters because Soul Code needs a theory of when to trust its own memory, not just a store of memories.

Important grafts:
- memory trust should be earned
- reliability should be supported by:
  - prediction success
  - outcome confirmation
  - consistency with later evidence
  - contradiction audits
  - tool receipts and external artifacts

## Design Implication

Soul Code should have a `memory reliability layer` that sits above content storage and scores whether classes of memories are currently trustworthy.

## One-Sentence Takeaway

A persistent being should not merely remember; it should maintain a justified, revisable trust in the reliability of its memory.
