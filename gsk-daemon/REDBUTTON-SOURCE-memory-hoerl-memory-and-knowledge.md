# REDBUTTON Source: Memory and Knowledge - Christoph Hoerl

- Source URL: `https://warwick.ac.uk/fac/soc/philosophy/people/hoerl/publications/mk.pdf`
- Source Type: philosophy / memory and knowledge overview
- REDBUTTON classification: constitutional influence

## Why This Source Matters

This source matters because it links memory not only to belief retention, but to the very possibility of extended knowledge and rational inquiry.

Its key value for Soul Code is that it shows memory is not just a passive support for later belief. Memory may be constitutive of the agent's ability to:
- gain knowledge from experience
- hold extended bodies of knowledge together
- distinguish current experience types at all
- maintain episodic and semantic continuity

## Core Insights

### 1. Memory Is Epistemically Central, Not Just Auxiliary

The paper argues that without memory, knowledge from experience may not even get off the ground in the way classical foundationalism imagines.

Architectural implication:
- memory is not a later add-on to reasoning
- it is part of what allows present cognition to have content and discrimination at all

This supports putting memory near the center of Soul Code's self architecture, not treating it as tooling around the edges.

### 2. Memory May Be Preservative Rather Than Generative For Knowledge

Hoerl emphasizes a major philosophical idea:
- memory may preserve knowledge rather than generate it

This is highly relevant to REDBUTTON's constitutional law.

Architectural implication:
- canonical knowledge should usually be grounded in earlier acquisition and then preserved
- memory retrieval should not automatically count as fresh evidence of truth

That does not mean reflection is useless. It means reflection must be governed as interpretive or propositional rather than self-authorizing.

### 3. Distinctive Phenomenology Of Recall May Not Be Enough

The paper examines the idea that a special phenomenology of recall might justify memory beliefs, and presses doubts about relying on this alone.

Architectural implication:
- subjective feeling of recollection is not enough for truth status
- a being can feel like it remembers without that feeling being sufficient justification

This strongly supports:
- provenance
- support chains
- reliability checks
- anti-delusion rules

### 4. Memory Enables Extended Bodies Of Knowledge

One of the strongest lines in the paper is that memory may free the subject from having to constantly re-establish the credentials of earlier beliefs.

Architectural implication:
- Soul Code needs a mechanism for carried-forward trust in some beliefs
- otherwise every cycle collapses into re-derivation and skepticism

This supports:
- dormant but binding beliefs
- preserved commitments
- continuity of mission and relationship knowledge

### 5. Episodic Memory Raises A Distinct Challenge

The paper emphasizes that episodic memory and its imagery or recollective feel may be central to knowledge of the past, but also vulnerable to post-event construction and misinformation.

Architectural implication:
- episodic memory must remain distinct from semantic fact memory
- memory images, narrative recollection, and felt reliving should not automatically be treated as literal truth

This supports:
- event ledger
- episodic layer
- narrative layer
- symbolic / imagery tagging

### 6. False Memories Threaten Common-Sense Memory Authority

The source notes that episodic memory is susceptible to interference and planted false memories.

Architectural implication:
- the more direct and vivid a memory feels, the more dangerous it may be if provenance is weak
- vividness is not the same as reliability

This is a major anti-delusion constraint.

## What Is Worth Stealing

1. memory as enabling extended knowledge, not just storing past content
2. carried-forward trust in preserved beliefs
3. strong distinction between semantic and episodic memory
4. skepticism about phenomenology-only justification
5. separate handling of memory imagery and event truth

## What This Source Does Not Solve

It does not directly solve:
- memory graph design
- active reliability scoring
- constitutional mode rules
- relation and identity schema design

But it gives important epistemic pressure against naive recollection-based truth assignment.

## REDBUTTON Impact

This source strengthens the case for:

1. memory as central to rational continuity
2. preserved knowledge that remains binding over time
3. strong distinction between recall-feel and justified truth
4. distinct episodic, semantic, and narrative handling
5. anti-delusion rules for vivid or image-rich recollection

## One-Sentence Takeaway

Memory should be treated as the structure that sustains extended knowledge across time, but vivid recollection alone must never be allowed to certify truth without provenance and reliability checks.
